# ⚖️ BMI Calculator — Streamlit

A simple interactive web application built with **Python and Streamlit** that calculates Body Mass Index (BMI) from a user's weight and height.

## Features

* Enter weight in kilograms
* Enter height in meters
* Calculate BMI instantly
* Display BMI value
* Display BMI category
* Simple and responsive Streamlit interface

## Technology Stack

* Python
* Streamlit

## BMI Formula

BMI is calculated using:

BMI = Weight (kg) / Height² (m²)

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/bmi-calculator-streamlit.git
```

### 2. Open the project folder

```bash
cd bmi-calculator-streamlit
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your web browser.
